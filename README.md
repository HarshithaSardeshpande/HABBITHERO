# 🌱 HabitHero

## Build Better Habits. Track Progress. Stay Consistent.

HabitHero is a daily habit tracking platform designed to help users build consistency in their everyday routines.

### Features

- 👤 Personal Profile
- ✅ Habit Creation
- 📅 Weekly Habit Scheduling
- 🔥 Streak Tracking
- 📊 7-Day Consistency Score
- 💊 Medicine Tracking
- 🔔 Reminder Notifications
- 💾 Browser Local Storage

### Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

### How It Works

1. Create your profile.
2. Add habits.
3. Select the days of the week.
4. Set reminder times.
5. Mark habits as completed.
6. Add and track scheduled medicines.
7. Monitor streak and consistency.
